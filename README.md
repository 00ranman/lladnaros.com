# lladnaros.com

Music-first carnival. Walk the grounds. Four tents. Four verses.

## Hostinger

This repo is a **prebuilt static site** plus a tiny Node server.

| Field | Value |
|---|---|
| Node.js | 22 |
| Package manager | npm |
| Build command | `npm run build` |
| Output directory | `dist` |
| Install command | `npm install` |
| Entry file | `server.js` |

If Git import is set to static website, deploy from `dist` (or repo root). Redeploy after each push.
